# Order Audit Workbench

这是一个本地网页版审单工作台。浏览器将文件交给本机 Python 服务处理，不会将 ERP 或库存文件上传到外部服务。运行状态保存在内存中，导出的审单结果会写入本机 `outputs/` 目录。

## 启动

需要 Python 3.10 或以上版本。在项目目录执行：

```shell
python -m pip install -r requirements.txt
python app.py --port 8793
```

1. Windows 也可以双击 `launch_hidden.vbs`，或使用 `start.bat` 启动。
2. 打开 `http://127.0.0.1:8793`。
3. 退出窗口时按 `Ctrl+C`停止服务。

## 每天使用

1. 在 ERP 区域上传今天从 ERP 导出的 `.xlsx`。
2. 在库存区域一次选择今天涉及的店铺库存文件。按本机配置的店铺映射自动匹配，也可以在右侧手动选择店铺。
3. 点击开始审单，结果默认先展示人工处理订单，可放行订单在下方折叠。
4. 可用搜索、店铺筛选、原因筛选快速定位，点击人工处理订单向上展开库存、价格和全部命中原因；列表支持整体收起。
5. 点击订单号、平台 SKU 或云仓 SKU 可以复制对应值，也可批量复制人工订单号和导出简洁 Excel。

人工列表会将仅包含同一个云仓 SKU 的多笔订单聚合成一组，跨店铺也可聚合。组记录显示订单数、购买总件数和人工原因；点击“复制本组订单号”可一次复制当前筛选条件下这一组的订单号，订单号之间以空格分隔。向上展开分组后，仍可逐笔查看完整原因及库存证据。含多个不同云仓 SKU 或缺失云仓 SKU 的订单单独显示，避免重复或遗漏。分组只改变页面展示，不改变审单结论与 Excel 导出。

## 审单规则

- 按 `warehouse_sku1` 汇总当天全部订单的需求。
- 有圈买库存时只判断圈买库存；圈买库存大于 0 但不足时人工处理。
- 圈买库存为 0、空白或负数时判断分销库存；分销足够时比较成本价与分销优惠价。
- 进入分销库存判断时，分销库存 `<= 6` 也需要人工处理，以便提前买入。
- 价格差值 `<= 3` 视为相同。
- `buyer_id + warehouse_sku1` 重复时相关订单全部人工处理，跨店铺也生效。
- 同一用户重复购买相同平台 SKU 时也会标记，并展示关联订单号。
- 单个订单内相同云仓 SKU 合计 `>= 2` 时人工处理。
- 库存表同一商品匹配多行时不合并，直接人工处理。
- 店铺与平台 SKU 必须精确匹配；只能找到云仓 SKU 对应库存时仍需人工确认。
- 完成前述检查后，对每条订单检查 `date_latest_ship`：最晚发货日期比当前日期晚 `6` 个日历日及以上时，标记为预售并转人工处理，不覆盖其他命中原因。
- 一个订单命中多个问题时展示全部原因。
- ERP 订单属于未识别店铺或店铺字段为空时，该订单转入人工处理并显示“订单所属店铺未识别，需要人工处理”，其他订单继续审核；已配置店铺仍须提供对应库存文件。

## 字段

ERP 至少需要 `refrence_no_platform`、`platform_seller_id`、`buyer_id`、`sku1`、`warehouse_sku1`、`qty1`，并可继续解析其他编号商品明细。

库存表需要亚马逊平台 SKU、云仓发货 SKU、圈买库存、分销库存（也支持“云仓库存”列名）、成本价、当前分销优惠价。

## 示例数据与本地配置

公开版本使用虚构的店铺、客户、订单、物流号和文件标识。真实业务表、数据库、截图、个人配置及运行结果不随仓库分发。示例值不能用于连接生产账号。

公开版只包含 `DEMOA` 等虚构店铺。使用前请在本机调整 `app.py` 中的 `STORE_ALIASES`，以及 `web/app.js` 中的 `stores` 和 `detectStore`，使其与自己的 ERP 店铺标识一致。请自行提供业务输入文件；个人配置应留在本机，不要将真实标识提交到公开仓库。

`outputs/`、Excel 输入表、截图、数据库、日志、本机快捷方式及便携版压缩包均被 Git 忽略。提交前仍需检查 `git diff --cached`，避免把业务内容写入源码、测试或说明文档。

## 验证

```shell
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
```

测试在临时目录生成虚构订单和库存，不依赖私人业务表。已安装 Chrome 时，启动本机服务后还可执行 `python tests/ui_visual_check.py` 检查电脑、窄屏页面和复制交互；可通过 `AUDIT_TEST_URL` 指定测试服务地址。
