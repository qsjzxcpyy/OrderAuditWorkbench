# Order Audit Workbench

这是一个本地网页版审单工作台。它不会把 ERP 或库存文件上传到外部服务，结果只保存在当前运行的内存中。

## 启动

1. 双击 `start.bat`，或在本目录执行 `python app.py --port 8793`。
2. 打开 `http://127.0.0.1:8793`。
3. 退出窗口时按 `Ctrl+C`停止服务。

## 每天使用

1. 在 ERP 区域上传今天从 ERP 导出的 `.xlsx`。
2. 在库存区域一次选择今天涉及的店铺库存文件。文件名包含 `Thryvix`、`Vynelito`、`XOCN` 或 `ZEIINPA` 时会自动匹配，否则在右侧手动选店铺。
3. 点击开始审单，结果默认先展示人工处理订单，可放行订单在下方折叠。
4. 可用搜索、店铺筛选、原因筛选快速定位，点击订单卡片右下角查看库存、价格和命中原因。
5. 点击复制人工订单号后可粘贴到 ERP，也可导出简洁 Excel。

## 审单规则

- 按 `warehouse_sku1` 汇总当天全部订单的需求。
- 有圈买库存时只判断圈买库存；圈买库存大于 0 但不足时人工处理。
- 圈买库存为 0、空白或负数时判断分销库存；分销足够时比较成本价与分销优惠价。
- 价格差值 `<= 3` 视为相同。
- `buyer_id + warehouse_sku1` 重复时相关订单全部人工处理，跨店铺也生效。
- 单个订单内相同云仓 SKU 合计 `>= 2` 时人工处理。
- 库存表同一商品匹配多行时不合并，直接人工处理。
- 一个订单命中多个问题时展示全部原因。

## 字段

ERP 至少需要 `refrence_no_platform`、`platform_seller_id`、`buyer_id`、`sku1`、`warehouse_sku1`、`qty1`，并可继续解析其他编号商品明细。

库存表需要亚马逊平台 SKU、云仓发货 SKU、圈买库存、分销库存（ZEIINPA 也支持“云仓库存”）、成本价、当前分销优惠价。
